# Baby Monitor app

feature plan

- Play and pause independently audio or video
- Secure lan-only communication channel, with clients (monitors) pairing with server (camera).
- network discovery
- Plugins for raw AV streams to:
    - reduce noise
    - detect silence
    - detect no movement
